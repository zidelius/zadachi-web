# Задачник

[Открыть Задачник](https://zidelius.github.io/zadachi-web/)

[Скачать Android-приложение](https://zidelius.github.io/zadachi-web/zadachi.apk)

- «Мой цикл» связывает выбранную цель с задачами, привычками и недельным итогом. Его можно настроить без ИИ.
- Недельная проверка связывает сигнал «если — то», обычный и облегчённый шаг, ожидание и факты. Отметки проверки хранятся в браузере; итог можно сохранить в заметки, а следующий шаг — добавить в календарь.
- Кнопка «ИИ» в шапке раздела готовит редактируемый запрос. Предложенные изменения применяются только после подтверждения.
- Жест «Назад» проходит по внутренним экранам и закрывает открытые окна. Для того же поведения системного жеста в Android установите APK 1.2.1 или новее.

## Проверка изменений

1. Создайте рабочую ветку от `main`.
2. Откройте пул-реквест в `main` и опишите, что изменилось и как это проверить.
3. Откройте ссылку на пул-реквест в разделе «Проверка кода» Codex, чтобы просмотреть изменения до слияния.
